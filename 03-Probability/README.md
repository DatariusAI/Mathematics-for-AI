# Probability for AI, ML and Data Science

**Why it matters:** Models output probabilities; uncertainty, Bayesian methods and generative models rest on probability.

- [Introduction to Probability (Blitzstein & Hwang)](https://stat110.net/)
- [Introduction to Probability (Grinstead & Snell)](https://math.dartmouth.edu/~prob/prob/prob.pdf)

## 🎓 Free courses
- [Harvard Stat 110](https://stat110.net/)
